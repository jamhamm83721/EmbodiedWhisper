# Editable hardware design

`EmbodiedWhisper.epro2` is an EasyEDA Pro project archive with both boards:

| Board | Schematic | PCB layout |
| --- | --- | --- |
| glasses | esp32 / P1 | esp32 |
| ring | Schematic1 / 4layer_esp32 | PCB3_1 |

The source editor version is 3.2.149.88089769. Open the project through the editor's
local-project/open-project function. The archive contains the project descriptor,
design records and three embedded preview images.

Account and editing-client metadata have been reset in the release copy. All
electrical, component, net, geometry and routing records are unchanged. The
fabrication exports are in each board's `gerbers.zip`; a layout preview is not a
manufacturing file. Library references and part numbers are retained for editing.
